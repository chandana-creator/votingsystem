# DBMS Voting System

## 📌 Overview
A database-driven voting system built using PHP and MySQL on the XAMPP server.  
This project demonstrates secure authentication, candidate management, vote casting, and real-time result tallying.

---

## ⚙️ Installation

1. Install [XAMPP](https://www.apachefriends.org/index.html).
2. Copy the project folder into the `htdocs` directory.
3. Open **phpMyAdmin** and import the `voting_system.sql` file.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Access the project at:  

http://localhost/voting_system


---

## 🚀 Usage

- **Admin Panel**:  
- Login with admin credentials.  
- Add/manage candidates.  
- View voting results.

- **Voter Panel**:  
- Register/login securely.  
- Cast votes for available candidates.  
- View confirmation of submission.
